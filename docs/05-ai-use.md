# 05 · Use AI where the result can be checked

| Task | Suitable assistance | Required verification |
|---|---|---|
| Explain a QC finding | Draft a concise explanation from computed values | Verify every number and the meaning of the rule |
| Normalize a CSV header | Suggest a field mapping | Confirm units and samples before accepting it |
| Extract a revision | Propose title-block fields | Human confirms the drawing ID and revision |
| Summarize a review log | Group open items by topic | Check omissions, ownership and issue status |
| Set design criteria | Identify information still needed | Criteria must come from the project basis and reviewer |

Keep source evidence separate from generated prose. A model response must not overwrite approved
criteria, change a drawing status or supply an assumed survey datum. Provide only data you are
permitted to use. The included demos are entirely local and do not transmit their inputs to a model.

Useful evaluation questions: Does the answer preserve units? Does it distinguish an assumption
from an observation? Does the citation support the claim? Does it ask for missing information?
The companion engineering AI evaluator demonstrates a small part of this process and deliberately
leaves reasoning and evidence judgments to a human.
