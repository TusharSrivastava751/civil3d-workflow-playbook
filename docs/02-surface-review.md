# 02 · Review surface inputs

1. Confirm the imported points and breaklines use the recorded horizontal and vertical units.
2. Check a few independently known control points before treating the surface as reliable.
3. Examine the surface boundary for holes, unintended extents and triangles spanning gaps.
4. Inspect breaklines and spot elevations around abrupt grade changes, walls and channels.
5. Record outliers for investigation; do not delete a point only because its elevation is inconvenient.
6. Check external references and data shortcuts for missing or stale sources.
7. Save a review record with source revision, issues, disposition and the responsible reviewer.

For a demonstration, intentionally introduce one unit mismatch and one boundary gap into a copy
of a synthetic model, then document how each is detected. No CAD execution is claimed here.

Do not create a real volume report until the base and comparison surfaces have a documented
purpose and overlapping review boundary. A screenshot can support a review but cannot replace
the underlying geometry, datum record and file versions.
