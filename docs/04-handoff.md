# 04 · Prepare a reviewable handoff

A proposed handoff package has a dated drawing register, an outgoing drawing list, the calculation
basis, the input/output versions and an open-issue record. Record review status separately from file
existence: a PDF in the folder is not proof of approval.

Use the drawing-revision demo to check identifiers, issue order and send dates. Confirm titles,
scale, units, revision notes and readable output manually. Ensure the report was regenerated from
the same source revision as the drawings. Hashes help identify a file but do not prove its content
is correct or approved.

| Handoff item | Evidence | Release condition |
|---|---|---|
| Drawing register | Drawing ID, revision, date, issue status | Matches intended outgoing issue |
| Quantity report | Method, units, input revision, differences | Material differences resolved or explicitly accepted |
| Basis record | Sources, criteria, datum | Reviewed for the intended use |
| Open items | Owner and disposition | Required issues closed by the responsible reviewer |

Before using any material in a public portfolio, rebuild it with synthetic data. Redacting a title
block alone may leave client coordinates, object names, xrefs, author metadata or confidential details.
This repository includes only newly authored text and sample records.
